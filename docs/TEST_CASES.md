## 执行准备

1. 在项目根目录启动服务，运行时保持终端打开：

   ```powershell
   python .\local-api\server.py
   ```

2. 在 Postman 右上角选中“本地预约服务”，确认环境变量：

   | 变量名 | 值或用途 |
   |---|---|
   | `base_url` | `http://127.0.0.1:8000`，末尾不加 `/` |
   | `username` | `admin` |
   | `password` | `password123` |
   | `token` | 由成功的鉴权请求保存 |
   | `booking_id` | 由成功的创建预约请求保存 |

3. 带 JSON 请求体的请求使用 `Content-Type: application/json`。
4. 需要有效鉴权的更新、删除请求，在 Headers 中填写 `Cookie: token={{token}}`。
5. 服务重启后，原来的 token 和预约全部失效，需要重新获取 token 并创建预约。

### 鉴权异常

- “获取token_错误密码”：使用 `POST {{base_url}}/auth`，用户名保留 admin，密码单独改为 `wrong_password`。错误密码请求不要复用成功请求中保存 token 的脚本，也不要覆盖环境中的正确密码。
- 测试更新、删除鉴权异常前，先使用“创建预约”准备一条仍存在的预约。正常流程中的预约如果已经删除，需要重新创建。
- “未携带token”：删除或取消勾选 Cookie 请求头，确认 Postman Cookie 管理器也没有自动发送该地址的 token Cookie。
- “token无效”：Headers 使用 `Cookie: token=invalid_token`，不要修改环境中的有效 token。
